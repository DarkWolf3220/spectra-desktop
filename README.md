# Spectra Desktop

Aplikacja na komputer dla [Spectry](https://spectrachat.pl), prywatnego komunikatora bez reklam i bez śledzenia.

To repozytorium służy tylko do pobierania instalatorów. Kod źródłowy aplikacji nie jest tu publikowany.

## Pobieranie

Najnowsza wersja: **[Releases](https://github.com/DarkWolf3220/spectra-desktop/releases/latest)**

| System | Plik |
| --- | --- |
| Windows 10/11 (64-bit) | `Spectra-<wersja>-win-x64.exe` |
| Linux (dowolna dystrybucja) | `Spectra-<wersja>-linux-x86_64.AppImage` |
| Linux (Debian, Ubuntu, Mint, Pop!_OS) | `Spectra-<wersja>-linux-amd64.deb` |

### Windows

Uruchom pobrany plik `.exe` i przejdź przez instalator.

Instalator nie ma jeszcze podpisu cyfrowego, więc Windows może pokazać okno "System Windows ochronił ten komputer". Kliknij **Więcej informacji**, a potem **Uruchom mimo to**.

### Linux

**AppImage:** nadaj plikowi prawo do uruchamiania i odpal go:

```
chmod +x Spectra-*.AppImage
./Spectra-*.AppImage
```

**.deb:**

```
sudo apt install ./Spectra-*.deb
```

## Aktualizacje

Aplikacja sama sprawdza aktualizacje i instaluje je przy następnym uruchomieniu (Windows i AppImage). Beta testerzy Spectry dostają też wersje oznaczone jako **Pre-release**.

## Problemy

Błędy i pomysły zgłaszaj przez aplikację albo na [spectrachat.pl](https://spectrachat.pl).
